COGNITARA

Adaptive Learning Intervention System Using AI

About the Project

COGNITARA is an AI-powered educational platform designed to identify students' learning difficulties, recommend personalized learning interventions, and track their learning progress through assessments.

Objectives

- Identify topics where students struggle.
- Recommend suitable learning resources and practice exercises.
- Track student performance over time.
- Explore AI-driven personalized learning.

Technology Stack

- Python
- Flask
- HTML, CSS, JavaScript
- SQLite
- Machine Learning

Project Status

Currently in the initial development phase.

Team

COGNITARA — Project-Based Learning (PBL), 2nd Year B.Tech.

Future Scope

- Personalized AI recommendations.
- Student performance dashboard.
- Adaptive quizzes and learning analytics.
